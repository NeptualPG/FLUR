# Day #1

I started building a basic API using Express and MongoDB.
I created simple GET endpoints and tested them using curl to understand how data flows between the server and the client.

I also began organizing the project by creating models and routes, which helped me understand how to structure a backend application properly.

The goal of this project is to learn by building. Instead of only watching tutorials, I’m applying what I learn immediately and using this project as a foundation for a bigger idea I already have planned.

- Created basic routes
